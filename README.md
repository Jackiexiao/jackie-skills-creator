# jackie-skills-creator

一键装好热门自媒体创作技能（懒人版）。
从选题到视觉到发布，一套跑通。

## 一键安装

```bash
npx skills add Jackiexiao/jackie-skills-creator --all
```

> 这条命令适用于几乎所有主流 AI 编程工具（Claude Code / Codex / Trae / OpenClaw 等）。

## 这套适合谁

- 自媒体创作者 / 博主 / 独立开发者做内容
- 需要“高频稳定输出”而不是偶发灵感的人

## 包含技能（9）+ 直接可用示例

- `social-content`：按平台写内容
  - 示例：`同一个话题分别写小红书、X、公众号三个版本。`
- `copywriting`：标题、开头、CTA
  - 示例：`给这篇文章写 10 个更高点击率标题。`
- `copy-editing`：润色与降噪
  - 示例：`把这段口播稿改得更口语、更自然。`
- `canvas-design`：海报/封面/静态视觉
  - 示例：`做一张“AI 提效清单”封面图，极简科技风。`
- `remotion-best-practices`：视频内容脚本与动画结构
  - 示例：`帮我设计 60 秒产品介绍动画分镜。`
- `ui-ux-pro-max`：视觉和交互增强
  - 示例：`优化我的个人主页视觉层次，让作品更突出。`
- `algorithmic-art`：生成独特视觉素材
  - 示例：`生成一套可重复风格的抽象背景图用于视频封面。`
- `web-design-guidelines`：网页设计规范化
  - 示例：`审查这个落地页视觉，指出“廉价 AI 感”并修正。`
- `tailwind-design-system`：Tailwind 设计系统搭建
  - 示例：`基于 Tailwind 建一套按钮/卡片/输入框设计规范。`

## 快速用起来（3 步）

1. 一键安装
2. 先跑“选题 + 标题 + 封面”三件套
3. 再扩展到视频与完整内容矩阵
