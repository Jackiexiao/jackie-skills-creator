# jackie-skills-creator

一键装好热门自媒体创作技能（懒人版）。
从选题到文案到视觉，一套跑通。

## 一键安装

```bash
npx skills add Jackiexiao/jackie-skills-creator --all
```

> 适用于几乎所有主流 AI 工具（Claude Code / Codex / Trae / OpenClaw 等）。

## 包含技能（13）+ 示例

- `social-content`：同一主题生成多平台文案
  - 示例：同一话题输出小红书 / X / 公众号三版
- `copywriting`：标题、开头、CTA 强化
  - 示例：给文章写 10 个高点击标题
- `copy-editing`：润色降噪，提升可读性
- `canvas-design`：海报/封面快速出图
- `remotion-best-practices`：视频脚本与动画结构
- `ui-ux-pro-max`：视觉与交互质感升级
- `algorithmic-art`：生成独特视觉背景
- `web-design-guidelines`：页面审美规范化
- `tailwind-design-system`：Tailwind 设计系统规范
- `baoyu-cover-image`：中文内容封面图快速生成
  - 示例：生成一张“AI 周报”公众号封面图
- `baoyu-comic`：漫画风格配图生成
- `baoyu-infographic`：信息图/数据图可视化表达
- `ai-image-generation`：通用 AI 配图生成
